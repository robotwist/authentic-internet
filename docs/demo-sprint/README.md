- `01-epics.csv` — four epics (spine, stability, juice, PM)
- `02-stories-tasks.csv` — 15 stories/tasks; **Parent** column must match your real Jira epic keys (see `jira-epic-keys-template.txt`)
- `03-sprint-calendar.csv` — optional calendar seed
- Airtable: `airtable-stories-fields.txt`, `airtable-stories-seed.csv`
